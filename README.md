# Godudel

A Strudel-inspired coding assistant for Godot.

Godudel is planned as a Godot editor extension that helps developers explore, write, and iterate on Godot projects through an interactive coding workflow.

## Status

Early development — project structure and first feature are not yet defined.

## Goals

- Provide an interactive coding experience inside Godot
- Help write and understand GDScript
- Make rapid experimentation feel approachable
- Keep the workflow focused on the current project and scene
